# 🌡️ Conversor de Temperatura

Aplicação Vue 3 + TypeScript para conversão entre escalas de temperatura (Celsius, Fahrenheit e Kelvin).

## 🚀 Como executar

```bash
# Instalar dependências
npm install

# Executar em modo de desenvolvimento
npm run dev

# Build para produção
npm run build
```

## 📦 Tecnologias

- Vue 3
- TypeScript
- Vite
- Tailwind CSS

## ✨ Funcionalidades

- ✅ Conversão automática entre Celsius, Fahrenheit e Kelvin
- ✅ Validação de valores (Kelvin >= 0)
- ✅ Interface moderna e responsiva
- ✅ Componentes reutilizáveis
- ✅ Tipagem TypeScript completa
